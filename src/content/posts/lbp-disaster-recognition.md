最近在 ROS 2 + Gazebo 巡检小车项目中，需要通过摄像头识别不同类型的灾害场景，例如建筑废墟、山体滑坡、受损车辆等。

在正式研究分类模型之前，我决定先从经典的纹理特征提取算法 LBP 入手，尝试完成一个简单的灾害场景识别系统。

本次实验主要解决三个问题：

1. LBP 如何将一张图片转换成纹理特征？

2. 不使用深度学习，能否完成五类灾害场景分类？

3. 当图片出现明显光照变化时，识别结果是否依然可靠？

本文将结合 Python、OpenCV 和实际实验数据，记录完整的实现过程。

## 一、认识 LBP：如何提取图片纹理？

LBP（Local Binary Pattern，局部二值模式）是一种经典的纹理特征描述方法。

它不直接判断图片中有什么物体，而是通过比较局部像素之间的灰度关系，提取图片中的纹理信息。

### 1.1 LBP 的计算原理

以一个 3×3 灰度区域为例：

```text
10   20   30
40   25   60
70   80   90
```

中心像素为 25。

将周围八个像素分别与中心像素比较：

- 大于或等于中心像素，记为 1。

- 小于中心像素，记为 0。

得到：

```text
0    0    1
1    C    1
1    1    1
```

从左上角开始，按照顺时针方向读取：

**00111111 = 63**

这样，原本的 3×3 灰度区域就被转换成了一个整数编码。

![图 1：3×3 邻域的 LBP 编码计算示意](/images/lbp/lbp-encoding-demo.png)

### 1.2 为什么 LBP 可以描述纹理？

不同区域的灰度变化方式不同，因此产生的 LBP 编码分布也可能不同。

例如：

- 平坦区域：**周围像素与中心像素差异较小**。

- 边缘区域：**中心像素两侧存在明显灰度变化**。

- 复杂纹理区域：**局部灰度关系更加多样**。

LBP 就是通过统计这些局部模式，间接描述整张图片的纹理特征。

需要注意，LBP 主要提取局部灰度关系，并不具备直接理解物体语义的能力。

## 二、手动实现基础 LBP

理解原理后，接下来使用 NumPy 实现基础 LBP，而不是直接调用现成的特征提取函数。

### 2.1 图像预处理

首先使用 OpenCV 读取图片，将其转换为灰度图，并统一调整为 256×256。

```python
import cv2
import numpy as np

image = cv2.imread("test.png")

if image is None:
    raise FileNotFoundError("图片读取失败")

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
gray = cv2.resize(gray, (256, 256))
```

灰度化的目的是让后续计算集中在像素的灰度大小关系上。

### 2.2 LBP 核心实现

```python
def calculate_lbp(gray):
    center = gray[1:-1, 1:-1]

    neighbors = [
        gray[:-2, :-2],
        gray[:-2, 1:-1],
        gray[:-2, 2:],
        gray[1:-1, 2:],
        gray[2:, 2:],
        gray[2:, 1:-1],
        gray[2:, :-2],
        gray[1:-1, :-2]
    ]

    lbp = np.zeros(center.shape, dtype=np.uint8)

    for i, neighbor in enumerate(neighbors):
        lbp |= (
            (neighbor >= center).astype(np.uint8)
            << (7 - i)
        )

    return lbp
```

这段代码最关键的部分是：

```python
neighbor >= center
```

它负责判断邻域像素与中心像素的大小关系。

而：

```python
<< (7 - i)
```

则负责将每次比较得到的 0 或 1 放入对应的二进制位置。

由于采用八邻域计算，每个像素最终会得到一个 0～255 之间的 LBP 编码。

## 三、从 LBP 特征图到灾害场景分类

得到 LBP 特征图后，还不能直接完成图片分类。

因为我们需要将不同图片转换成可以相互比较的特征向量。

### 3.1 提取 256 维直方图

基础八邻域 LBP 共有 $2^8 = 256$ 种可能的编码。

因此，可以统计每种编码在图片中出现的频率，生成一个 256 维直方图。

```python
lbp = calculate_lbp(gray)

hist = np.bincount(
    lbp.ravel(),
    minlength=256
).astype(np.float64)

hist /= hist.sum()
```

归一化后，直方图所有元素之和为 1。

至此，一张图片就被转换成了一个固定长度的纹理特征向量。

### 3.2 使用卡方距离比较图片

为了比较两张图片的纹理差异，本次实验采用卡方距离：

$$
D(H_1, H_2) = \frac{1}{2} \sum_i \frac{(H_1(i) - H_2(i))^2}{H_1(i) + H_2(i) + \varepsilon}
$$

对应的 Python 实现：

```python
def chi_square(h1, h2):
    return 0.5 * np.sum(
        (h1 - h2) ** 2 /
        (h1 + h2 + 1e-10)
    )
```

在本次实验中，距离越小，表示两张图片的 LBP 直方图越接近。

![图 3：测试样本与五类参考样本的卡方距离矩阵](/images/lbp/lbp-distance-matrix.png)

### 3.3 五类灾害场景识别

本次实验使用五种灾害场景：

| 类别     | 英文名称        |
| -------- | --------------- |
| 建筑废墟 | collapsed_ruins |
| 受损车辆 | damaged_vehicle |
| 山体滑坡 | landslide       |
| 救援营地 | rescue_camp     |
| 被困人员 | trapped_people  |

每类准备两张图片，共十张。

其中第一张作为参考样本，第二张作为测试样本。

分类流程如下：

```text
输入测试图片
    ↓
灰度化、统一尺寸
    ↓
提取 LBP 特征
    ↓
生成 256 维直方图
    ↓
与五类参考样本计算卡方距离
    ↓
选择距离最小的类别
    ↓
输出分类结果
```

初步实验中，五张测试图片全部识别正确。

不过，目前每类只有一张参考图片和一张测试图片，样本数量较少，因此这一结果只能作为算法可行性验证，不能直接代表真实巡检环境中的识别准确率。

## 四、实验重点：LBP 真的不受光照影响吗？

在学习 LBP 时，经常会看到它具有一定光照鲁棒性的介绍。

这是因为，当像素灰度发生严格单调变化，并且邻域像素之间的大小关系保持不变时，LBP 编码也可以保持不变。

但实际图片经过亮度增强后，是否仍然满足这一条件？

为此，我设计了一组光照干扰实验。

### 4.1 实验设计

通过调整测试图片的亮度，模拟三种光照条件：

| 条件           | 亮度系数 |
| -------------- | -------- |
| Normal（正常） | 1.0      |
| Dark（暗光）   | 0.5      |
| Bright（强光） | 1.5      |

亮度调整代码：

```python
def change_brightness(image, alpha):
    return np.clip(
        image.astype(np.float32) * alpha,
        0,
        255
    ).astype(np.uint8)
```

保持五类参考图片不变，分别对三种光照条件下的测试图片进行分类。

### 4.2 实验结果

| 灾害类别     | 正常    | 暗光    | 强光    |
| ------------ | ------- | ------- | ------- |
| 建筑废墟     | ✓       | ✓       | ✗       |
| 受损车辆     | ✓       | ✓       | ✗       |
| 山体滑坡     | ✓       | ✓       | ✓       |
| 救援营地     | ✓       | ✓       | ✓       |
| 被困人员     | ✓       | ✓       | ✓       |
| **正确数量** | **5/5** | **5/5** | **3/5** |

实验发现：

正常和暗光条件下，五张测试图片均分类正确。

但在强光条件下，出现了两次误分类：

- 建筑废墟被识别为救援营地。

- 受损车辆被识别为建筑废墟。

为什么只是增强了亮度，分类结果就发生了变化？

### 4.3 寻找原因：像素饱和

进一步对建筑废墟测试图片进行亮度分析，得到以下数据：

| 光照条件 | 平均灰度 | 饱和像素比例 |
| -------- | -------- | ------------ |
| Normal   | 120.97   | 0.00%        |
| Dark     | 60.20    | 0.00%        |
| Bright   | 174.57   | 16.90%       |

强光条件下，有 11075 个灰度像素达到最大值 255。

例如，原本不同的像素：

```text
180   200   230
```

在增强 1.5 倍并截断后，会变成：

```text
255   255   255
```

这时，原本存在的灰度差异消失了。

由于我们的 LBP 使用 `>=` 进行比较，当邻域内多个像素同时达到 255 时，就更容易出现八个比较结果全部为 1 的情况。

也就是 LBP 编码：

$$
11111111_2 = 255
$$

进一步统计发现：

| LBP 编码 | 正常光照 | 强光   |
| -------- | -------- | ------ |
| 255      | 8.11%    | 17.52% |

编码 255 的出现频率明显增加，说明强光处理后，图片的 LBP 特征分布发生了变化。

### 4.4 特征变化如何导致误分类？

继续观察建筑废墟图片与参考样本之间的卡方距离：

| 光照条件 | 建筑废墟距离 | 救援营地距离 |
| -------- | ------------ | ------------ |
| Normal   | 0.007517     | 0.007902     |
| Bright   | 0.023281     | 0.022537     |

正常光照下，建筑废墟距离更小，因此分类正确。

但强光条件下，救援营地的距离反而更小，最终导致分类错误。

这次实验呈现出一条清晰的现象链：

**强光增强 → 部分像素饱和 → LBP 编码分布变化 → 特征距离排序逆转 → 分类错误。**

这说明 LBP 对光照具有一定鲁棒性，但这种鲁棒性并不是无条件成立的。像素截断导致的灰度信息丢失，是本次实验中值得关注的影响因素。

## 五、总结

通过本次实验，我们完成了一个从基础 LBP 到灾害场景分类的完整实践：

- 实现八邻域 LBP 特征提取。

- 使用 256 维直方图描述图片纹理。

- 基于卡方距离完成五类灾害场景分类。

- 通过光照实验，分析强光导致的识别错误。

这次实践让我认识到，LBP 虽然实现简单，也能够有效描述部分局部纹理，但它并不是一个可以直接解决所有场景识别问题的算法。

尤其是在巡检小车实际运行时，摄像头还会受到拍摄距离、观察角度、光照和图像质量等因素影响。

下一篇将继续研究 **Uniform LBP 与特征优化**，尝试在降低特征维度的同时，分析分类性能是否会受到影响，并逐步向实际巡检场景靠近。
