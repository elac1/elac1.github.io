## 阶段 1：打基础（1-2 个月）

**C 语言**——指针、结构体、函数指针、内存管理。这是所有系统编程的根基，ROS 2 的核心就是 C++ 写的。

跟着做：
- [ ] 能用指针遍历数组
- [ ] 能用函数指针实现简单的"回调"
- [ ] 知道 malloc/free 什么时候会崩

**Linux 基础**——至少要会在 Ubuntu 里装软件、写 shell 脚本、用 git。推荐直接装一个 Ubuntu 虚拟机或双系统，Windows 搞 ROS 会有很多莫名其妙的问题。

## 阶段 2：学 C++（1 个月）

不需要学完整个 C++ 标准。重点掌握：

- 类和对象（封装、继承、多态）
- STL 容器（vector、map、unordered_map）
- 智能指针（shared_ptr、unique_ptr）
- lambda 表达式

ROS 2 的 API 大量使用智能指针和回调，这两块必须熟。

## 阶段 3：ROS 2 入门（2-3 个月）

官方教程跟着走一遍就行，重点理解：

- 节点、话题、服务、动作
- 参数服务器
- launch 文件
- colcon 构建

**动手做**：写一个"听到键盘输入就发布速度指令"的小节点，再写一个"订阅速度指令并打印"的小节点。两个节点能通信就算入门了。

## 阶段 4：专题深入

根据方向选：
- **导航**：Nav2 栈，SLAM Toolbox
- **机械臂**：MoveIt 2
- **视觉**：OpenCV + 消息过滤
- **仿真**：Gazebo / Ignition

## 一句话总结

**不要跳步**。很多人上来就学 ROS 2，遇到一点报错就卡壳，因为底层缺东西。按这个顺序来，虽然慢一点，但每一步都是扎实的。
