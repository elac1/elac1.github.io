文件名以 `_` 开头的文章是草稿，不会出现在博客列表中，也不会被发布。

写好之后，把文件名开头的 `_` 去掉，它就会变成正式文章。

## 每个文件前的模板

```
title: '文章标题'           # 必填,字符串
pubDate: '2026-09-18'       # 必填,日期格式 YYYY-MM-DD
description: '文章摘要'      # 可选,一句话简介,会显示在列表和 SEO
tags:                        # 可选,标签数组
  - 标签1
  - 标签2
category: 分类名             # 可选,文章分类
featured: false              # 可选,是否推荐文章,默认 false
image: '/path/to/cover.png' # 可选,封面图路径
```
