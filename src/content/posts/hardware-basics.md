## 控制板：你的电路大脑

这是整个系列的起点。后面讲的舵机、IMU、舵机控制板，最终都要接到它上面，由它来指挥。

### 1. 它到底是个什么东西

你可以把控制板理解成一块**能听懂程序的小电脑**。

它自己不能动，也不能发光，但它能：

- 读按钮按没按
- 读传感器测到了什么
- 控制灯亮不亮
- 控制电机转不转、舵机转到哪

你写什么程序，它就按什么逻辑干活。

常见的 Arduino Uno、ESP32、树莓派 Pico，都是控制板。

### 2. 为什么需要它

如果没有控制板，你想让灯按一下亮、再按一下灭，得自己搭一堆电路，改起来还麻烦。

有了控制板，你只需要写几行代码：

```cpp
if (按钮按下) {
  灯亮;
} else {
  灯灭;
}
```

逻辑变了，改代码就行，不用重新焊电路。

**这就是控制板最大的价值：用程序代替复杂的电路。**

### 3. 它怎么干活

控制板的工作方式就三步，一直循环：

1. **读输入**：看引脚上的电压是高还是低，判断按钮、传感器状态
2. **做判断**：按你写的程序逻辑计算
3. **写输出**：把结果写到引脚上，控制灯、电机、舵机

举个具体例子：

- 你接了一个按钮和一个 LED
- 程序里写：按钮按下 → LED 亮
- 控制板就一直循环：读按钮 → 判断 → 写 LED

整个过程每秒重复几万次，所以你感觉不到延迟。

### 4. 引脚是什么，为什么重要

引脚就是控制板边上那一排金属针。

它们是控制板和外界沟通的唯一通道：

- **输入引脚**：接按钮、传感器，读外部信号
- **输出引脚**：接 LED、继电器、舵机信号线，控制外部设备
- **电源引脚**：5V、3.3V、GND，给外设供电
- **模拟引脚**：读电位器、光敏电阻这类连续变化的信号

没有引脚，控制板就是一个孤岛，什么都干不了。

### 5. 怎么用：从接线到跑起来

**第一步：接线**

以 Arduino Uno 为例：

- LED 正极 → 数字引脚 D13
- LED 负极 → GND（中间串一个电阻）
- 按钮一端 → D2，另一端 → GND

**第二步：写程序**

```cpp
void setup() {
  pinMode(13, OUTPUT);
  pinMode(2, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(2) == LOW) {
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}
```

**第三步：上传**

用 USB 线连电脑，点上传，程序就跑起来了。

**使用注意：**

- 外设多或功率大时，**独立供电**，不要直接从控制板取电
- 独立电源的 GND 要和控制板的 GND **共地**
- 引脚有电流上限，直接驱动电机容易烧板

### 6. 一句话记住它

控制板就是**用程序控制电路的小电脑**。

- 读输入 → 做判断 → 写输出
- 引脚是它和外界沟通的通道
- 程序代替复杂电路


## 舵机：它能精准转到指定角度，靠的是什么？

上一节讲了控制板，这一节讲它最常控制的东西之一：舵机。

2. 电位器反馈当前实际角度
3. 控制电路计算两者差值
4. 差值不为零 → 驱动电机转动
5. 差值归零 → 电机停止

所以舵机不是“转到就断电”，而是**一直在微调**，抵抗外力干扰，保持角度稳定。

### 4. 减速齿轮组的作用

直流电机本身转速很高，但扭矩很小。

减速齿轮组的作用：

- **降速**：把高转速降到适合控制的速度
- **增扭**：把低扭矩放大到能带动负载
- **自锁**：部分舵机齿轮组还有自锁能力，断电后不易被外力转动

这也是舵机能用在机械臂、云台等场景的原因。

### 5. 位置反馈的作用

没有反馈，电机不知道自己转到了哪，只能“盲转”。

电位器（或编码器）的作用就是**把角度变成电信号**，让控制电路知道当前实际位置。

这就是“闭环”的关键：**有反馈，才能修正。**

### 6. 怎么用：接线与驱动

**接线（三根线）：**

- 棕/黑 → GND
- 红 → VCC（5V）
- 橙/黄 → 信号线

**Arduino 驱动（Servo 库）：**

```cpp
#include <Servo.h>

Servo myservo;

void setup() {
  myservo.attach(9);  // 信号线接 D9
}

void loop() {
  myservo.write(0);    // 转到 0°
  delay(1000);
  myservo.write(90);   // 转到 90°
  delay(1000);
  myservo.write(180);  // 转到 180°
  delay(1000);
}
```

**使用注意：**

- 舵机多或功率大时，**必须独立供电**，不要直接用 Arduino 的 5V。
- 独立电源的 GND 要和 Arduino 的 GND **共地**。
- 连续旋转舵机调的还是 `write()`，但数值表示速度而不是角度：`write(90)` 停转，`write(0)` / `write(180)` 是两个方向满速，所以不能用来定位。

### 7. 两种类型

| 类型 | 内部逻辑 | 表现 |
|------|----------|------|
| 角度舵机 | 反馈角度，闭环定位 | 转到指定角度并保持 |
| 连续旋转舵机 | 去掉角度反馈，只控速度 | 像减速电机一样持续转 |

连续旋转舵机本质上是**把闭环定位改成了开环调速**，所以它不能定位。

### 8. 小结

舵机的核心不是“电机”，而是**电机 + 反馈 + 控制**构成的闭环系统。

- 电机提供动力
- 齿轮组降速增扭
- 电位器反馈位置
- 控制电路比较并修正
- 使用时注意独立供电和共地

正是这个闭环，让舵机能够精准转到指定角度，并在外力干扰下保持住。


## 舵机控制板：为什么需要它，什么时候可以不用它

舵机多了，控制板就带不动了。这一节讲专门帮控制板分担舵机驱动任务的小助手。

### 1. 先搞清楚它是什么

舵机控制板本质上是一个**专门帮控制板分担舵机驱动任务的小助手**。

上一节讲舵机时，我们说的是“一个舵机怎么接、怎么用”。但现实情况是：你做一个机器人，可能需要同时控制 6 个、8 个甚至 12 个舵机。

这时候，如果还用控制板的引脚一个一个去驱动舵机，会遇到两个问题：

- **引脚不够用**：Arduino Uno 总共就十几个数字引脚，接 6 个舵机就占掉一半
- **电流带不动**：控制板的引脚输出电流只有几十毫安，而舵机工作时需要几百毫安甚至更多，直接接上去要么带不动，要么烧板

舵机控制板就是来解决这两个问题的。

### 2. 它和控制板是什么关系

可以用一个比喻来理解：

- **控制板**：大脑，负责想“要做什么动作”
- **舵机控制板**：肌肉，负责把“动作用力做出来”

大脑发出指令（比如“第 3 号舵机转到 90°”），肌肉负责把这个指令变成实际的动作，同时提供足够的“力气”（电流）。

所以系统连接是这样的：

**控制板 → 舵机控制板 → 舵机**

控制板把指令通过串口发给舵机控制板，舵机控制板再产生舵机需要的信号，并用自己的电源给舵机供电。

### 3. 它到底解决了什么问题

**第一，省引脚。**

一个舵机控制板通常有 8 路、16 路甚至 32 路舵机接口。控制板只需要用两根线（TX/RX）和舵机控制板通信，就能控制十几个舵机。

**第二，解决供电。**

舵机控制板有独立的电源输入接口，可以接电池或电源适配器，专门给舵机供电。控制板不再需要从自己的 5V 引脚给舵机供电，避免了电流过大烧板的风险。

**第三，简化接线。**

如果没有舵机控制板，每个舵机都要单独接电源正极、电源负极、信号线，十几根线缠在一起，很容易接错。有了舵机控制板，舵机直接插在板子上的 3Pin 接口里，电源和地线共用，接线干净很多。

### 4. 什么时候你不需要它

如果你只控制 **1～2 个舵机**，而且用的是 Arduino 这类控制板，直接接上去就行，不需要额外的舵机控制板。

舵机数量超过 3～4 个，或者舵机功率比较大（比如 MG996R 这种金属齿舵机），就需要考虑加一块舵机控制板了。

一个简单的判断标准：

- **舵机少、小**：直接接控制板
- **舵机多、大**：控制板 + 舵机控制板

### 5. 它和控制板上的程序有什么区别

控制板上的程序，写的是“逻辑”：什么时候动、动到哪、按什么顺序动。

舵机控制板上的程序（或固件），负责的是“执行”：把控制板发来的指令翻译成舵机需要的信号，同时管理电源和保护电路。

有些舵机控制板还支持**脱机运行**：你预先编排好一组动作存在板子里，控制板不用一直发指令，舵机控制板自己就能按顺序执行。

### 6. 一句话记住它

舵机控制板就是**帮控制板分担舵机驱动和供电的专用小板**。

- 控制板管逻辑，舵机控制板管执行
- 解决引脚不够和电流不够两个问题
- 舵机少的时候不需要，舵机多的时候离不开


## IMU：它是什么，能干什么，通常和什么结合

控制板能控制舵机了，但它还不知道自己是什么姿态。这一节讲给控制板提供姿态信息的模块。

### 1. 先搞清楚 IMU 是什么

IMU 是 **Inertial Measurement Unit** 的缩写，中文叫**惯性测量单元**。

你可以把它理解成一个**专门感知“自己怎么动”的小模块**。

它不像按钮只能告诉你“按没按”，也不像光敏电阻只能告诉你“亮不亮”。IMU 告诉你的是：

- 现在倾斜了多少度
- 正在往哪个方向转
- 转得有多快
- 有没有在加速

所以它常用在需要**知道自己姿态和运动状态**的地方，比如无人机、平衡车、机器人、手机屏幕旋转。

### 2. 它里面有什么

IMU 内部通常有两类传感器：

- **加速度计**：测量三个方向的加速度，能感知倾斜和振动
- **陀螺仪**：测量三个方向的角速度，能感知旋转的快慢

有些 IMU 还会加上：

- **磁力计**：测量地磁方向，能感知朝向（类似电子罗盘）

这三样合在一起，就是一个完整的姿态感知系统。

### 3. 原理：它为什么能知道姿态

IMU 的工作逻辑可以概括为一句话：

**通过测量加速度和角速度，推算出物体当前的姿态和运动状态。**

具体来说：

1. 加速度计测量重力在三个轴上的分量 → 算出倾斜角
2. 陀螺仪测量三个轴的旋转速度 → 积分后得到角度变化
3. 两者数据融合 → 得到稳定、准确的姿态

单独用加速度计，振动时会抖；单独用陀螺仪，时间长了会漂。融合在一起，才能又稳又准。

### 4. 它通常放在哪

IMU 一般固定在需要被感知的物体上，越靠近重心越好，轴向要和物体对齐。

比如无人机固定在机架中心，平衡车固定在车体底部，机器人固定在躯干或头部。

### 5. 它通常和什么结合

**和控制板结合：让控制板知道“现在是什么姿态”**

控制板本身不知道物体是平放还是倾斜，也不知道是在转还是静止。IMU 把这些信息读出来，控制板才能根据姿态做判断。

比如平衡车：IMU 读出倾斜角，控制板算出该往哪边加速，再驱动电机。没有 IMU，控制板就是个“睁眼瞎”。

**和舵机结合：让舵机知道“该往哪转、转多少”**

舵机本身只能执行角度，不知道外界发生了什么。IMU 感知到姿态变化后，控制板才能算出舵机应该转到哪，去补偿或调整。

比如云台稳定：IMU 感知到抖动，控制板控制舵机反向补偿，让摄像头保持水平。没有 IMU，舵机只能盲转，稳定就无从谈起。

### 6. 一句话记住它

IMU 就是**感知自己怎么动的模块**。

- 加速度计管倾斜和振动
- 陀螺仪管旋转快慢
- 融合之后知道姿态
- 固定在物体上，越靠近重心越好
- 和控制板结合，让它知道姿态
- 和舵机结合，让它知道该往哪转


## 舵机 + 控制板 + IMU + 舵机控制板，能做什么

四个部件都认识了，这一节把它们串起来，看看凑在一起能做什么。

### 1. 先理清四个东西各自负责什么

| 部件 | 角色 | 负责什么 |
|------|------|----------|
| 控制板 | 大脑 | 读传感器、做判断、发指令 |
| IMU | 姿态感知 | 告诉控制板“现在倾斜多少、转多快” |
| 舵机控制板 | 舵机管家 | 帮控制板驱动多个舵机，提供独立供电 |
| 舵机 | 执行器 | 按指令转到指定角度 |

把它们串起来，就是一个**能感知姿态、能做出判断、能精确控制角度的闭环系统**。

### 2. 它们怎么配合

工作流程一句话：

**IMU 读姿态 → 控制板算偏差 → 舵机控制板驱动舵机 → 舵机转动修正 → IMU 再读姿态**

这是一个不断循环的闭环。IMU 是眼睛，控制板是大脑，舵机控制板是肌肉，舵机是手脚。

### 3. 能做什么

**自平衡云台**

这是最典型的组合。

- IMU 固定在摄像头上，感知抖动和倾斜
- 控制板算出需要补偿的角度
- 舵机控制板驱动两个舵机，一个管俯仰，一个管横滚
- 舵机反向转动，抵消抖动

效果：不管你怎么晃动手持支架，摄像头画面始终水平稳定。

**四足机器人（机器狗）**

- IMU 固定在躯干上，感知身体的倾斜和姿态变化
- 控制板算出四条腿各自该怎么调整
- 舵机控制板驱动每条腿上的多个舵机，调整关节角度
- 身体倾斜时自动修正步态，保持平衡

效果：机器狗走路时能自己站稳，你推它一下，它会调整四条腿重新找回平衡。

### 4. 一句话总结

这四个东西凑在一起，就是一套**能感知姿态、能自主判断、能精确执行**的闭环控制系统。

- IMU 负责“感觉”
- 控制板负责“思考”
- 舵机控制板负责“发力”
- 舵机负责“动作”

云台和四足机器人，就是这套组合最直接的两个例子。
